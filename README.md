# FINDRA - Lost and Found Management System

## Overview
FINDRA is a web-based Lost and Found Management System developed to help users report, search, and recover lost items efficiently. The system provides a centralized platform for managing lost and found records while improving communication between users and administrators.

The application allows users to register lost or found items, upload item images, search for matching records, and submit ownership claims. It also includes QR code-based item registration and email notification functionality to improve item recovery efficiency.

---

# Features

## User Features
- User Registration and Login
- Secure Authentication using JWT
- Report Lost Items
- Report Found Items
- Upload Item Images
- Search and Filter Items
- Submit Item Claims
- QR Code Item Registration
- Email Notifications
- Responsive User Interface

## Admin Features
- Admin Dashboard
- Manage Lost and Found Reports
- Verify Claims
- Manage Users
- Monitor System Activities

# System Architecture

The system follows a client-server architecture:

- Frontend handles user interactions and UI rendering.
- Backend manages APIs, authentication, and business logic.
- MongoDB stores system data.
- Cloudinary stores uploaded images.
- Nodemailer handles email notifications.
